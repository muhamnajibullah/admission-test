Admission Test Admin Guide

Initial setup

Import database/schema.sql, followed once by database/seeds/001_initial_admin.sql, into the alazkasch_admission_test database. Copy config/database.example.php to config/database.php and enter the database credentials. Normal application requests never create, alter, or delete schema. For later database changes, import only missing ordered files from database/migrations; never import the baseline again.

Sign in

Open login.html and sign in with the configured administrator account. Authentication is maintained by a secure server session.

Units

Create a Unit, select Jakarta or Surabaya, and make it available for registration. A Unit becomes available to students after it has an active Question Bank.

Question Banks

Create a bank for a Unit, choose its passing score and exam duration, then enter four answer choices for every question. Question order and answer-choice order can be shuffled independently. The first bank for a Unit becomes active automatically; use Activate or Inactivate to control availability. When editing, a bank can be moved to another Unit. It stays inactive if that Unit already contains another question bank. The Save Question button saves the complete bank while keeping the editor open.

Formulas and images

Use the formula button to open the LaTeX preview and insert a formula. Questions and answer choices accept JPG, PNG, or WebP images. Source files above 2 MB are compressed automatically before they are stored; each source file may be up to 20 MB and 6000 × 6000 pixels.

Exam access

Generate one global four-digit token and choose its validity in seconds or minutes. Token validity controls access only; the Question Bank duration controls the exam deadline.

Results

Test Results are loaded in pages of 20 records. Use the Unit filter to narrow the list.
